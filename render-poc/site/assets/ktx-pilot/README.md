# Generic Einar jacket texture diagnostic

Three full-resolution jacket-main maps, derived from the existing CC BY 4.0 Einar export. Original source and attribution are in the repository README. KTX2 UASTC quality 3, Zstd18, box mips. Colour is sRGB; normal and packed roughness/metalness are linear. This is a lossy experimental overlay, not a production download reduction. Original geometry, source textures and viewer versions are retained. Normal-angle quality gate currently fails; visual diagnostic only.
